# 网络基础
- DNS（Domain Name System，域名系统）
- TCP（Transmission Control Protocol，传输控制协议）
- - TCP Reset（TCP Reset，TCP 重置）
- IP（Internet Protocol，互联网协议）
-  HTTP（HyperText Transfer Protocol，超文本传输协议）
-  HTTPS（HyperText Transfer Protocol Secure，安全的超文本传输协议）
-  TLS（Transport Layer Security，传输层安全协议）
- -  SNI（Server Name Indication，服务器名称指示）
-  DPI（Deep Packet Inspection，深度包检测）

# 中国网络特殊情况（GFW）
-  GFW（Great Firewall of China，中国长城防火墙）
-  DNS 污染（DNS Poisoning / DNS Spoofing / DNS Cache Poisoning）
-  IP 封锁（IP Blocking）
-  TCP 重置注入（TCP Reset / RST Injection）
-  残留阻断（Residual Blocking）

# 绕过方式（代理）
-  Proxy（Proxy，代理）
-  本地代理软件（Clash、V2Ray、Shadowsocks）
- -  加密隧道
- -  国外中转服务器
- -  不同模式：Rule / Global / TUN（系统代理）
-  代码层面配置（proxy 参数 或 环境变量）
-  其他工具：WireGuard 等

# OSI 7层模型（从下到上）

| 层级  | 名称（中英文）          | 通俗比喻  |  主要干什么？ |
|---|------------------|---|---|
| 7 | 应用层 Application  | 你写信的内容 | 提供网络服务（浏览器、微信、邮件、游戏）
| 6 | 表示层 Presentation | 把信翻译成对方能看懂的语言 | 数据格式转换、加密/解密、压缩
| 5 | 会话层 Session      | 建立和维护“对话通道” | 管理连接的建立、保持、断开
| 4 | 传输层 Transport    | 负责把信安全送到对方手上 | TCP（可靠）、UDP（快）
| 3 | 网络层 Network      | 决定走哪条路（路由） | IP地址、路由器
| 2 | 数据链路层 Data Link  | 小区门口的保安和快递站 | MAC地址、交换机、错误检查
| 1 | 物理层 Physical     | 实际的公路、电线、光纤 | 传输0和1的电信号、光信号
