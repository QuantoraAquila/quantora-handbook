## 2.0 Python 各主版本重要改动
### 🐍 Python 1.x（1991–2000）
- Python 1.0 (1994)
  - 初始正式版，包含 print 语句、异常处理、函数、模块、基本数据类型（list/dict/string）。
- Python 1.5
  - 引入 包（packages） 概念，可以有层级目录结构。
- Python 1.6
  - 支持 Unicode 字符串（有限），以及垃圾回收改进。

---
### 🐍 Python 2.x（2000–2020）
- Python 2.0 (2000)
  - 引入 垃圾回收（GC, 基于引用计数 + 循环检测）。
  - 列表推导式（list comprehensions）。
- Python 2.2 (2001)
  - 引入 迭代器 和 生成器（yield 关键字）。
  - 新式类（统一类模型，继承自 object）。
- Python 2.7 (2010)
  - 最后一个 2.x 版本，加入部分 Python 3 特性回溯移植（如 dict 推导式，set 字面量）。
  - 长期支持直到 2020 年 1 月正式停止维护。

---
### 🐍 Python 3.x（2008–现在）
#### Python 3.0 (2008)
- 重大变革，不兼容 Python 2
  - print 变为函数：print("hello")。
  - str 默认使用 Unicode（解决多语言支持）。
  - 除法运算 / 总是返回浮点数，// 才是整除。
  - 移除旧式类（只保留新式类）。
  - range() 返回惰性序列对象（类似迭代器）。
#### Python 3.3
* 引入 虚拟环境（venv）。
* 添加 yield from（生成器委托）。
#### Python 3.4
* 引入 asyncio（异步 I/O 框架）。
* enum、pathlib 模块。
#### Python 3.5
* 支持 async / await 语法（协程正式进入语言核心）。
* 矩阵乘法运算符 @。
#### Python 3.6
* f-string 格式化字符串：f"Hello {name}"。
* 字典保持插入顺序（后来在 3.7 成为语言规范）。
#### Python 3.7
* 数据类 dataclasses。
* 异步生成器、异步推导式。
* breakpoint() 内置函数。
#### Python 3.8
* 海象运算符 :=（赋值表达式）。
* 仅限位置参数语法（def func(a, b, /, c, d)）。
#### Python 3.9
* 字典合并与更新运算符：d1 | d2、d1 |= d2。
* 字符串方法 .removeprefix()、.removesuffix()。
#### Python 3.10
* 结构化模式匹配（match-case）。
* 更强的类型提示（list[str] 取代 List[str]）。
#### Python 3.11
* 显著的性能提升（约 10–60% 提速）。
* 更好的错误提示与 traceback（精确到表达式）。
#### Python 3.12
* 更快的 CPython（持续性能改进）。
* 改进 f-string 语法（支持更复杂的表达式）。
* 删除了过时的 wstr 接口、旧 distutils。
#### Python 3.13
* 继续性能优化。
* 改进了内置函数错误提示。
* 更多标准库现代化清理。

---
### 📌 总结
* **1.x**：Python 初始功能建立，基本语法与模块系统。
* **2.x**：引入生成器、迭代器、新式类，奠定现代 Python 基础。
* **3.0**：彻底清理历史包袱（print、Unicode、除法）。
* **3.3–3.5**：协程、asyncio、async/await，异步编程进入核心。
* **3.6–3.10**：现代语法糖（f-string、海象运算符、match-case）。
* **3.11+**：大幅提升性能，逐步向更快的 CPython 迈进。

## 3.0 Python 的基础通常可以分为两个核心部分：

---
### 1. 语言核心（Language Core）

这是 Python 的**语法**、**数据模型**和**运行时行为**的核心部分，决定了你写 Python 代码的基本规则和行为。包括：

- 语法与关键字：if/else、for/while、def、class、async/await、模式匹配 match/case 等。

- 内置数据类型：如 int、float、str、list、dict、set、tuple。

- 内置函数：len()、range()、zip()、enumerate() 等。

- 错误和异常机制：try/except/finally、自定义异常类。

- 内存管理和对象模型：如引用计数、垃圾回收、对象的可变性与不可变性。

**特点**：语言核心是 Python 本身的一部分，不依赖任何外部库，所有 Python 实现（CPython、PyPy 等）都会遵循它的规范。

### 2. 标准库（Standard Library）

标准库是 Python 自带的一整套模块和包，提供了常用功能和工具，扩展了语言核心的能力，但不是语法本身的一部分。

- 模块示例：

  - 文件与操作系统：os、sys、shutil

  - 数据结构与算法：collections、heapq、bisect

  - 网络和协议：socket、http、urllib

  - 数据处理：json、csv、xml

  - 异步和并发：asyncio、threading、multiprocessing

  - 类型提示和工具：typing、dataclasses

- 特点：

  - 使用时需要 import 才能调用

  - 提供了大量通用功能，避免每个开发者都从零实现

  - 可以随着 Python 版本不断扩展或废弃模块

**总结**

- 语言核心：Python 的规则、语法和内置类型，是写代码的“底层语法骨架”。

- 标准库：Python 自带的模块集合，是“实用工具箱”，方便快速开发。

简单比喻：

- 语言核心 = 建筑的钢筋骨架

- 标准库 = 室内装修和工具设备

## 4.0 细分历代改动
把历代 Python 主要改动按 “语言核心（Language Core）” 和 “标准库（Standard Library）” 分类整理，这样能更清晰地看到哪些是语法和语言本身的变化，哪些是自带模块的功能增强。
### Python 1.x 系列（1991–2000）

| 主版本 | 改动                                   | 分类       |
| --- | ------------------------------------ | -------- |
| 1.0 | 函数定义、模块导入、异常处理、核心数据类型（list、dict、str） | 语言核心     |
| 1.5 | 包（package）机制引入（`__init__.py`）        | 标准库/模块管理 |
| 1.6 | Unicode 字符串支持、垃圾回收雏形                 | 语言核心     |
### Python 2.x 系列（2000–2020）

| 主版本    | 改动                           | 分类   |
| ------ | ---------------------------- | ---- |
| 2.0    | 循环垃圾回收、列表推导式、Unicode 加强      | 语言核心 |
| 2.2    | 新式类（继承 object）、迭代器与生成器       | 语言核心 |
| 2.7    | 集合推导式、字典推导式、整合部分 Python 3 特性 | 语言核心 |
| 2.x 整体 | 增加 itertools、collections 等模块 | 标准库  |
### Python 3.x 系列（2008–至今）

| 主版本  | 改动                                          | 分类             |      |
| ---- |---------------------------------------------| -------------- | ---- |
| 3.0  | `print()` 函数化、`str` 默认 Unicode、移除老式类和冗余语法   | 语言核心           |      |
| 3.3  | `yield from`、`importlib` 引入                 | 语言核心 + 标准库     |      |
| 3.4  | `asyncio` 库                                 | 标准库            |      |

| 3.6  | f-string、字典保持插入顺序（CPython 实现）               | 语言核心           |      |
| 3.7  | 数据类（`dataclasses`）、asyncio 改进               | 语言核心 + 标准库     |      |
| 3.8  | 海象运算符 `:=`、仅限位置参数                           | 语言核心           |      |
| 3.9  | 字典合并、移除旧兼容性      | 语言核心 |
| 3.10 | 模式匹配 `match/case`、类型提示增强                    | 语言核心           |      |
| 3.11 | 性能提升、异常回溯更精确                                | 语言核心 + 解释器实现优化 |      |
| 3.12 | per-interpreter GIL 实验、`typing` 优化          | 语言核心 + 解释器实现优化 |      |
| 3.13 | 性能、安全性增强、标准库优化                              | 语言核心 + 标准库     |      |
### 分类总结

1. 语言核心：语法、关键字、内置类型、生成器/迭代器、f-string、async/await、模式匹配等，直接影响 Python 代码行为。

2. 标准库：asyncio、dataclasses、collections、itertools 等模块，提供扩展功能，需要 import 才能使用。

3. 解释器实现优化（部分 3.11+）：性能提升、GIL 调整、异常回溯改进，不改变语法，但影响执行效率和调试体验。
