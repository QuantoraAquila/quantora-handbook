# 实用工具包
## pip
### 01 导出当前环境的包依赖到 requirements.txt 文件
在命令行（终端）中运行：
```
pip freeze > requirements.txt
```
✅ 说明：

* pip freeze 会列出当前环境中所有已安装的包及其版本号；

* \> 表示“重定向输出到文件”；

* 生成的文件内容类似这样：
```
redis==5.0.4
PyYAML==6.0.2
fastapi==0.115.0
uvicorn==0.30.6
```
💡 小贴士：

- 如果你在虚拟环境中（如 venv、conda、poetry env），
这条命令只会导出该环境下的包，非常安全。

## pipreqs
### 01 根据你的项目代码自动生成 requirements.txt 文件（只包含代码中真正被 import 到的包）。

在项目根目录下运行：
```
pipreqs . --force
```

参数说明：

* . → 指定当前目录；

* --force → 如果已有 requirements.txt，强制覆盖。

* 执行后会在当前目录生成（或覆盖）requirements.txt 文件，只包含项目中实际用到的依赖。
