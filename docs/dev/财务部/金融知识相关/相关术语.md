# 1、证券（instrument）市场相关
## 1.1 SPOT = 现货

- 英文原意： “Spot” 来自 “on the spot”，意思是 “立即交割”。

- 金融含义： 在现货市场中，买卖双方立即按当前价格（spot price）成交并交割。

- 对应场景： 你买 BTC-USDT，立即获得 BTC，没有杠杆、没有到期日。

✅ 总结： SPOT 表示 “即时交割的交易”，也就是 币币交易（现货）。

## 1.2 MARGIN = 杠杆交易

- 英文原意： “Margin” 是 “保证金” 的意思。

- 金融含义： 在保证金交易中，交易者只需支付一部分资金作为保证金，就能借入更多资金放大交易规模。

- 对应场景： 你用 1000 USDT 开多 BTC，但交易所允许你借入 4000 USDT，相当于开 5 倍杠杆。

✅ 总结： MARGIN 表示 “保证金交易”，即 币币杠杆市场。

## 1.3 SWAP = 永续合约

- 英文原意： “Swap” 本意是 “交换” 或 “掉期”，在金融衍生品中是一种 无到期日的互换合约。

- 金融含义： 永续合约其实是模仿 “掉期合约（Swap）” 的机制，价格通过资金费率不断锚定现货价格。

- 对应场景： 你开多 BTC-USDT-SWAP，没有交割日，每 8 小时结算一次资金费率。

✅ 总结： SWAP 表示 永续互换合约（Perpetual Swap），即常说的 永续合约。

## 1.4 FUTURES = 交割合约

- 英文原意： “Future” 就是 “未来”，Futures 指 期货合约。

- 金融含义： 双方约定在未来某个日期，以特定价格买卖标的资产。

v对应场景： BTC-USD-240628 表示 2024年6月28日交割的BTC期货合约。

✅ 总结： FUTURES 表示 有到期日的期货（交割合约）。

## 1.5 OPTION = 期权

- 英文原意： “Option” 就是 “选择权”。

- 金融含义： 期权是一种衍生品，赋予持有人在未来以特定价格买入或卖出资产的权利（但不是义务）。

- 对应场景： BTC-USD-240628-35000-C 表示到期日为 6月28日、行权价 35000、看涨（Call）的 BTC 期权。

✅ 总结： OPTION 表示 期权合约，拥有“权利但非义务”。

## 1.6 总结表：

| instType | 英文来源             | 中文含义 | 是否有杠杆 | 是否有到期日    |
| -------- | ---------------- | ---- | ----- | --------- |
| SPOT     | Spot Market      | 现货   | ❌     | ❌         |
| MARGIN   | Margin Trading   | 杠杆现货 | ✅     | ❌         |
| SWAP     | Perpetual Swap   | 永续合约 | ✅     | ❌         |
| FUTURES  | Futures Contract | 交割合约 | ✅     | ✅         |
| OPTION   | Option Contract  | 期权   | ✅     | ✅（特定日期行权） |
